    ¶ Attributes

    slotTemplate为 common、slot 类型已不再维护，此处仅对 tree 进行支持和更新

    需要平行列表的单选和多选请参考 vr-select(大数据量) 和 el-select

    selectedListDefault 即将废弃，以后请改为 v-model

    参数类型是否必须默认值说明
    v-modelArray否[]选中项 id 数组
    dataListArray是[]数据源（同树数据源要求）
    minSelectNumNumber否0最少选几项
    maxSelectNumNumber否100000000最多选几项
    placeholderString否''默认展示
    placementString否''（1.2.21 新增）打开方向，默认""时，自动判断下方是否有足够空间展示，否则向上打开，"bottom"指定只向下打开，"top"指定只向上打开
    filterableBoolean否false是否可搜索
    widthDataString否'220px'宽度
    multipleBoolean否false是否多选
    issingleleafBoolean否falseslotTemplate='tree'时生效，是否只能选择叶子【true-联动并只返回叶子节点数据，false-不联动，返回叶子+树干数据】
    getAllSelectedNodesBoolean否false是否需要返回所有选中的节点，在issingleleaf=true时，若需要返回联动的枝干节点，请传true
    slotTemplateString否'tree''tree'--树形列表
    selectedListDefaultArray否[]修改页面进入时，默认选中数据，以 ID 数组传入
    disabledBoolean否false是否禁用
    themeString否'light'主题，支持'light','dark'
    needDistinctBoolean否true是否对文本框中的“已选择：1”进行去重处理
    disabledNoCheckBoolean否false是否枝干节点不能 check

    ¶ methods

    setSelectList 和 setDefaultSelect 即将废弃，以后请使用 v-model

    事件名称说明
    setDefaultSelect设置默认选中接收 1 个参数，需要选中项的 key 数组,返回一个 Promise，resolve 结果和 multipleSelect 回调结果数据类型相同
    setSelectList设置选中接收 1 个参数，key 数组，当在页面内发生选项变化时可调用，返回 promise，防止在部分情况下因调用顺序问题导致的错误
    getSelectValues获取选中项需要主动获取选中项时调用此方法，返回结果数组
    showDataList主动触发列表显示--
    multipleRemoveAll移除全部选中项--
    multipleRemove移除某一个选中项接收 1 个参数{key:''}对象(兼容低版本已使用的场景)，或者直接传 id，即 multipleRemove({key:111})或者 multipleRemove(111)

    ¶ Events

    multipleSelect选择结果回调方法无论单选多选，列表还是树，当选中/清空选中时触发该方法，参数为选中结果数组[{key:'', value:''},{key:'', value:''}]
